# SDLC y Stack Tecnológico del Proyecto

## Metodología de Trabajo
Se adopta el marco **Scrum** con iteraciones (Sprints) de 2 semanas:
- **Sprint Planning:** Definición del objetivo del sprint y selección de historias de usuario.
- **Daily Standup:** Reunión diaria de alineación de 15 minutos.
- **Sprint Review & Retrospective:** Demostración del incremento entregado y retroalimentación para mejora continua.

## Stack Tecnológico
- **Lenguaje de Programación:** Java 21 LTS
- **Gestor de Construcción:** Apache Maven
- **Framework Principal:** Spring Boot 3.x / Jakarta EE
- **Base de Datos:** PostgreSQL
- **Puerta de Enlace:** Kong API Gateway
- **Contenedores y Orquestación:** Docker / Podman / K3s
- **Calidad y CI/CD:** SonarQube, GitHub Actions / Runners locales, automatización de SBOM (Software Bill of Materials).
