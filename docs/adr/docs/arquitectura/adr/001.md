# ADR 001: Migración del Monolito a Microservicios mediante el Patrón Strangler Fig

- **Estado:** Aprobado
- **Fecha:** 2026-09-21
- **Autores:** Equipo de Arquitectura

## Contexto
El sistema monolítico actual presenta problemas de escalabilidad, despliegues complejos y acoplamiento estrecho entre dominios de negocio. Reescribir el sistema completo desde cero mediante una estrategia Big Bang conlleva un riesgo inaceptable para la continuidad de la operación.

## Decisión
Adoptar el patrón **Strangler Fig (Higuera Estranguladora)** para migrar de forma gradual el monolito a una arquitectura de microservicios:
- Interceptar todas las peticiones en la capa de borde (API Gateway).
- Extraer paulatinamente los dominios de negocio a microservicios independientes.
- Redirigir el tráfico del monolito hacia los nuevos microservicios de manera incremental.

## Consecuencias
### Positivas
- Reducción sustancial del riesgo operativo en cada despliegue.
- Entrega de valor continuo e incremental al negocio.
- Aislamiento de fallos y capacidad de escalamiento independiente.

### Desafíos
- Gestión temporal de datos duales y consistencia eventual entre el monolito y los servicios.
- Mantenimiento de interoperabilidad durante la etapa de transición.
